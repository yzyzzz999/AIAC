# 部署限制

1. 当前 v8 L1 参数为工程候选，`production_ready=false`。
2. 在线 consumer 默认旁路 CHTD 温度计算，以四路头温测点作为 PMV 空气温度。
3. 旁路 MRT 当前以 `AC_FrntInCarT` 作为代理，并非完整辐射模型。
4. 风速由总风量和三路风门位置估算，当前无左右独立实测风量。
5. `feet_temp_c` 是兼容模型状态字段；旁路运行时可能保持旧值。
6. HTTP `cabin_temp_c` 当前映射为主驾 PMV 空气温度，命名偏差尚未修复。
7. 后排 PMV 未接入。
8. 图像 API 不可用时服务继续运行，衣着和代谢率使用默认值。

上述限制不影响当前服务启动和 API 契约，但在量产标定或字段语义调整前必须保留说明。
